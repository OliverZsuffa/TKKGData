# TKKGData

The shared, validated source of truth for structured TKKG episode and release data.

This repository is being established as the central data project for TKKGTracker, TKKGDownloader, and future TKKG tools. Its initial architecture and migration plan are documented in `requests/001-shared-tkkg-dataset/`.

Planning only: the application migration and scraper implementation have not yet been approved or started.
